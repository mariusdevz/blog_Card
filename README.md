# Blog Card

## About

A simple blog card built as part of a DevChallenges frontend challenge.

The project displays a blog preview with an image, category, title, description, and author information.

## Technologies

- HTML5
- CSS3

## Features

- Minimalist card design
- Responsive layout
- Styled typography
- Author information section

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
